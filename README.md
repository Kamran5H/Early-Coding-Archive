# 📜 Early Coding Archive — Kamran Ashraf

A cherished retrospective collection of the earliest Python scripts, learning milestones, and foundational chemistry data models written by **Muhammad Kamran Ashraf** during the inception of his programming journey.

---

## 🌟 Archive Contents

| File | Description | Domain / Tech |
| :--- | :--- | :--- |
| **Pehla pehla code, aiiaiiaii.py.txt** | *\"My First Code\"* — Scikit-Learn linear regression model correlating molecular weights with chemical boiling points (Water, Ethanol, Methane, Benzene, Acetone) to predict Propanol. | Machine Learning & Computational Chemistry |
| **python_assignment_request.py** | An interactive full-screen Tkinter prompt celebrating early Python milestones and playfully requesting real-world coding challenges and tasks. | Tkinter / Desktop GUI |
| **eautiful_message.py** | Multi-colored desktop message presenter with customized palette cycling and emotional typography. | Tkinter GUI |
| **multi_coloured_message_Version2.py** | Enhanced iteration of the desktop text card with dynamic geometry and custom color tokens. | Tkinter GUI |
| **Ladooooo .py** | Terminal-based stylized banner output built with Rich & PyFiglet ASCII art. | CLI & Terminal Styling |

---

## 🚀 Historical Significance

These scripts capture the pivotal moment where chemistry, curiosity, and code converged — laying the groundwork for later enterprise-grade projects including **QAU Kalam**, **Source Genius**, **Disk Optimizer Pro**, and **Urdu Poetry Studio**.
